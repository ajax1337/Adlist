# Domain inventory attribution — 2026-10-28

Only observed exact hostnames were added. Existing parent-domain coverage was checked first, avoiding redundant rotating CDN entries. No synthetic shared-cloud parent rules were introduced. All pre-existing entries are retained.

New inventories are disabled on registration. These files include functional APIs, subscriptions, deep links, feature flags, healthcare and checkout services, as well as analytics and advertising. They are not malware determinations.

## Exclusions and false positives

Unverified brand-like names, opaque shared CDNs, customer cloud tenants and certificate validation hosts are not added to active service lists. In particular, no blanket `amazonaws.com`, `cloudfront.net`, `akamaihd.net`, `akamaized.net` or `fastly-edge.com` rule was added.

[Grammarly’s administrator documentation](https://support.grammarly.com/hc/en-us/articles/115000090731-WebSockets-Support-Q-A-for-System-Administrators) confirms `*.grammarly.io` is legitimate Grammarly infrastructure. A prior automated impersonation allegation is not accepted as evidence of phishing. Name-only allegations for other domains remain unresolved.
